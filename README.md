# Tech-Classified-Ads-Web-Application
Project Overview

This is a Tech Classified Ads Web Application built using Vanilla JavaScript and Bootstrap 5.
The application simulates a real-world classified platform where users can browse, search, and post tech-related ads.

All data is handled dynamically on the frontend using JavaScript (no backend integration).

**Features**

1. Live search across multiple fields
2. Category-based filtering
3. Location-based filtering (via modal selection)
4. User authentication (Signup/Login using local/session storage)
5. Add new posts with image preview (Base64 encoding)
6. Fully responsive design (Bootstrap 5)
7. Dynamic DOM rendering without page reload


**Key Concepts Used**

DOM Manipulation
Event Handling
Array Filtering & Searching
Async JavaScript (Promises, setTimeout)
Browser Storage (localStorage / sessionStorage)
Responsive UI Design

**Tech Stack**
HTML5
CSS3
Bootstrap 5
Vanilla JavaScript
